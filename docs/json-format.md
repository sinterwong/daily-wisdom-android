# JSON 句库格式 v1

这是通用的本地文件接口，可由脚本、AI、笔记工具或人工生成。没有服务器 API，不绑定内容来源、作者或手机品牌。

将 UTF-8 编码的 `.json` 文件保存到手机，然后在应用中点击「导入 JSON」。应用校验后显示标题、条数和第一条预览，确认后再保存并切换。文件通过系统文件选择器读取，不要求全盘存储权限。

```json
{
  "schemaVersion": 1,
  "id": "my-notes",
  "title": "我的随手记",
  "author": "我",
  "items": [
    { "id": "001", "text": "先记录观察，再区分事实与判断。", "source": "工作笔记" },
    { "id": "002", "text": "给自己留一点不被安排的时间。" }
  ]
}
```

## 字段

| 位置 | 字段 | 要求 |
|---|---|---|
| 句库 | `schemaVersion` | 必填，数字 `1` |
| 句库 | `id` | 必填，1～80 个英文、数字、点、横线或下划线；首字符是英文或数字 |
| 句库 | `title` | 必填，非空文本，最多 100 字符 |
| 句库 | `author` / `translator` | 可选，最多各 200 字符 |
| 句库 | `source` | 可选，最多 500 字符 |
| 句库 | `items` | 必填，1～10000 条内容 |
| 每条内容 | `id` | 建议填写；唯一文本或整数，最多 128 字符；省略时根据正文生成稳定 ID |
| 每条内容 | `text` | 必填，非空正文，最多 4000 字符；桌面显示摘要，应用中可滚动看全文 |
| 每条内容 | `author` / `source` | 可选，覆盖句库默认值；限制同上 |
| 每条内容 | `page` / `endPage` | 可选 PDF 页序，正整数，最大 1000000；结束页不能小于起始页 |

整个文件最大 5 MiB。未知字段在 v1 导入时忽略；不会自动执行 HTML、代码或访问内容中的链接。

## 更新、切换和收藏

- 不同句库 `id`：添加独立句库，可随时切换；收藏、随机顺序和停留状态各自独立。
- 相同句库 `id`：确认后更新该句库。**仍存在的内容 ID 保留收藏**；重排随机阅读顺序，并结束停留。删除的内容不再保留收藏。
- 因此更新正文时，尽量保持内容 `id` 不变。省略 ID 后若修改正文，系统会把它视为新内容。
- `builtin-advice` 保留给内置示例，不能覆盖。导出内置示例时自动使用 `advice-copy`，可以作为自己的副本导入。
- 导出包含规范化后的句库内容与 ID，不包含收藏及阅读进度。
- 多个桌面小组件共享当前选择的句库。

## 简写与旧文件兼容

`items` 也可写成字符串数组：`["第一条", "第二条"]`。相同正文会生成相同 ID，重复时请改用对象并给出不同 ID。

也兼容旧的顶层数组，比如 `[{"id":1,"text":"第一条","page":9}]` 或 `["第一条","第二条"]`。自动命名为「导入句库」，根据完整文件生成句库 ID；更新旧数组内容通常会变成新句库。长期维护推荐使用完整对象格式。
