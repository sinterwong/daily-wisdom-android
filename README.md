# 一日一句

把喜欢的书摘、笔记或提醒放在安卓桌面上，每天看一句。可以用内置内容，也可以导入自己的句库。无需注册，离线使用。

## 安装

在 [下载页面](https://github.com/sinterwong/daily-wisdom-android/releases/latest)展开 **Assets**，选择以 `.apk` 结尾的文件，下载到手机后安装。需要 Android 8.0 或更新版本，以及支持小组件的桌面。

v0.5.0 及更早版本更新时可能提示签名冲突。请先导出需要保留的句库，再卸载旧版并安装新版。**卸载会清空收藏和阅读进度，导出的句库不包含这些数据。**

## 放到桌面

打开应用，点击 **放到手机桌面 → 请求添加**，在弹出的窗口里确认。

如果没有弹窗，也可以从手机桌面添加：

1. 长按桌面空白处，进入“小组件”或“窗口小工具”。
2. 找到“一日一句”，把卡片拖到桌面。
3. 长按卡片调整大小。默认是 2×2，也可以拉成 1 行 4 列的横条。部分桌面需要先进入“全部”或“Android 小部件”。

想让字更大，打开应用里的 **组件字号**。可选 14～24，默认 20，设置会应用到所有卡片。卡片空间不足时会自动调整显示；没显示完的内容，点一下正文就能看全文。

更新应用后，已有卡片会保留原来的大小。想用新的默认尺寸，可以移除后重新添加。

## 每天怎么用

- **换一句**：立刻换一条。默认每天自动换一次，同一天保持不变，一轮读完再重复。
- **收藏**：把喜欢的内容留下来，在“我的收藏”中搜索、查看全文或取消收藏。
- **让它停留**：暂时不再自动换句。点击“恢复更新”即可继续。
- **切换句库**：选择桌面要显示的内容。每个句库分别保存收藏和阅读进度。

多个桌面卡片共享当前句库和当天内容。小尺寸卡片会隐藏部分按钮，打开应用也能完成这些操作。

## 加入自己的内容

### 导入文件

点击 **导入 JSON**，选择文件，确认预览后即可使用。

可以下载 [示例句库](examples/my-library.json)，把里面的文字换成自己的内容；也可以先“导出当前句库”，照着修改后再导入。详细格式见 [JSON 文件说明](docs/json-format.md)。

每个句库有一个 `id`。导入相同 `id` 的文件会更新原句库，导入不同 `id` 的文件会增加一个句库。更新前会让你确认。

### 在手机上修改

进入 **管理内容**，可以搜索正文、作者和来源。点击条目看全文，再选择“编辑”或“删除”；列表顶部可以新增条目。

内置内容和导入内容都能直接修改，不用创建副本。修改保存在本机，并同步到桌面。想把修改后的内容留一份文件，点击 **导出当前句库**。

## 常见问题

**为什么今天没有自动换句？**

先检查有没有开启“让它停留”。如果没有，打开应用会检查日期并刷新。系统省电或后台限制也可能让更新延迟，可以在手机设置中允许应用后台运行。

**为什么桌面上找不到小组件？**

先打开应用一次，再回桌面重试。在组件列表中检查“全部”或“Android 小部件”。不同桌面的入口名称和可用格数可能不同。

**换手机或卸载前怎么保留内容？**

切换到要保留的句库，逐个导出 JSON，在新设备上重新导入。目前没有云同步，导出文件也不包含收藏和阅读进度。
